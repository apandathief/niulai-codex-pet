# 牛来 宠物操作手册

版本：1.0  
适用日期：2026-08-27  
宠物名称：牛来  
宠物 ID：`niulai`

> 说明：OpenAI 当前公开文档中未提供本地自定义宠物的完整规范。本手册依据这台 Mac 上现有 Codex/ChatGPT 桌面版的实际界面与本地加载规则整理，并已对“牛来”宠物包进行验证。应用更新后，入口名称或格式可能发生变化。

## 一、快速启用

1. 完全退出并重新打开 Codex/ChatGPT 桌面应用。
2. 打开“设置”，进入 **Pets（宠物）**。
3. 在 **Pick a pet（选择宠物）** 中找到 **牛来**，点击 **Select（选择）**。
4. 点击 **Wake Pet（唤醒宠物）**，宠物会出现在桌面浮层中。
5. 在 **Pet size（宠物大小）** 滑杆中调整显示尺寸。

如果宠物已经被唤醒，同一位置会显示 **Tuck Away Pet（收起宠物）**；点击即可暂时关闭浮层，不会卸载宠物。

## 二、日常使用

### 1. 看状态

宠物会跟随 Codex 任务状态自动切换动作，不需要手动播放动画。

| 宠物表现 | 含义 | 建议操作 |
|---|---|---|
| 待机 | 当前没有需要立即处理的事项 | 可直接开始新任务 |
| 工作/奔跑 | Codex 正在思考、执行命令、搜索或编辑文件 | 等待任务继续运行 |
| 等待 | 任务需要你的输入、选择或授权 | 打开旁边的任务提示并处理 |
| 完成待查看 | 任务已经完成，但结果尚未查看 | 点击完成提示或打开对应任务 |
| 受阻/失败 | 任务失败、被阻止或无法继续 | 打开提示查看原因并决定下一步 |
| 挥手 | 初次唤醒、问候或普通信息提醒 | 无须处理 |
| 跳跃 | 鼠标悬停等互动反馈 | 无须处理 |

### 2. 处理任务提醒

- 将鼠标移到宠物或活动提示附近，可查看当前任务信息和可用操作。
- 点击任务提示，可打开对应任务查看完整内容。
- 当出现授权、问题或选项时，可直接在浮层中处理；若浮层无法完整显示，请打开对应任务处理。
- 完成提示可关闭；运行中的任务在界面提供停止按钮时可以停止。
- 活动较多时，可展开或收起活动列表。

### 3. 快速发起聊天

浮层出现 **Ask（询问）** 或 **Start new chat（开始新聊天）** 输入框时，可直接输入内容并发送。宠物已有活动时，新输入通常会创建新任务；跟进已有任务时，建议先点击对应活动，再在该任务内回复。

### 4. 收起与再次唤醒

- 暂时隐藏：设置 → Pets → **Tuck Away Pet**。
- 再次显示：设置 → Pets → **Wake Pet**。
- 收起只影响浮层显示，不会删除宠物文件，也不会清除任务记录。

## 三、个性化与刷新

在“设置 → Pets”中：

- **Pet size**：调整宠物大小。
- **Open folder**：打开本地自定义宠物目录。
- **Refresh**：重新扫描本地宠物；手动替换文件后应点击一次。
- **Select**：切换到指定宠物。
- **Create**：进入新宠物创建流程。

“牛来”已经针对默认宠物浮层制作，不需要修改应用本体或 `app.asar`。

## 四、宠物文件与备份

当前安装位置：

```text
~/.codex/pets/niulai/
├── pet.json
└── spritesheet.webp
```

- `pet.json`：名称、介绍、精灵表版本和图片路径。
- `spritesheet.webp`：全部动作帧，带透明背景。

备份时，把整个 `niulai` 文件夹复制到其他位置即可。恢复时，将完整文件夹放回 `~/.codex/pets/`，然后点击 **Refresh** 或重启应用。

请不要只复制其中一个文件，也不要让目录变成 `~/.codex/pets/某文件夹/niulai/` 这种多套一层的结构；应用只扫描 `pets` 目录下的直接子文件夹。

## 五、更新与卸载

### 更新形象

1. 先备份整个 `niulai` 文件夹。
2. 替换 `spritesheet.webp`；文件名不变时无须修改 `pet.json`。
3. 在设置中点击 **Refresh**，必要时完全退出并重启应用。

替换图片必须继续满足本手册末尾的技术规格，否则可能无法加载、动作错位或画面被裁切。

### 卸载

1. 先使用 **Tuck Away Pet** 收起宠物。
2. 通过 **Open folder** 打开宠物目录。
3. 将 `niulai` 文件夹移出 `pets` 目录；如需保留，建议移动到备份目录，不要直接删除。
4. 点击 **Refresh** 或重启应用。

## 六、故障排查

### 找不到“牛来”

1. 确认目录是 `~/.codex/pets/niulai/`，没有多套一层文件夹。
2. 确认其中同时存在 `pet.json` 与 `spritesheet.webp`。
3. 在设置 → Pets 中点击 **Refresh**。
4. 仍未出现时，完全退出并重新打开桌面应用。

### 能选中，但宠物没有出现

1. 点击 **Wake Pet**。
2. 将宠物大小调回中间位置，排除尺寸过小或位置不明显。
3. 检查是否位于其他显示器或屏幕边缘。
4. 收起后再次唤醒；仍无效时重启应用。

### 只有空白、图片错位或动作异常

- 精灵表必须是 WebP、透明背景、尺寸精确为 **1536 × 1872**。
- 版本 1 使用 **8 列 × 9 行**，单格 **192 × 208**。
- 不要裁切画布、改变行列数或随意调整帧位置。
- 确认 `pet.json` 中 `spritesheetPath` 仍为 `spritesheet.webp`。

### 应用更新后失效

自定义宠物位于用户目录，通常不会随应用更新一起被替换。先确认文件夹仍在，再点击 **Refresh** 并重启应用。如果新版应用改变了宠物格式，则需要按新版加载规则重新适配，不建议直接修改应用安装包。
